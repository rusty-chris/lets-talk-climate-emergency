# Adversarial design review — v3 → v3.1 (2026-08-16)

Independent critic-agent review of DESIGN.md v3 and DECISIONS.md. All 20 findings were incorporated into v3.1; disposition noted per finding.

## Verdict

This is an unusually self-aware design: the guaranteed-vs-measured discipline, the permission-first licensing posture, and the closed ChartSpec are genuinely strong, and the ADRs honestly record alternatives. But it is not yet hand-off-ready. It contains two blockers: the licensing invariants contradict the tier tables in a way that would cause an implementation agent to ship NC-conditioned text in the Apache-2.0 repo, and the flagship chart — the product's stated "wow moment" — is not expressible in the ChartSpec vocabulary the design defines. Beneath those, the mission-central severity-fidelity eval is under-specified to the point of being unimplementable as written, the MVP corpus is severity-skewed (Hansen in, IPCC assessed ranges out) in exactly the direction the project says it cannot afford, the runtime-vs-eval-time boundary of the checking pipeline is ambiguous, privacy/GDPR is entirely absent for a UK public deployment that logs user queries, and the 4–5 week Phase 1 is not credible. All of this is fixable within the design's own framework; none of it requires rethinking the architecture.

## Findings and disposition

1. **BLOCKER — UNEP mis-tiered; shipping rule keyed on wrong field.** Tier A placement + NC-conditioned terms meant an agent would commit UNEP text to the Apache-2.0 repo. → **Fixed:** UNEP moved to Tier B; all invariants re-keyed on `permitted_context`; only `open` documents ship in-repo.
2. **BLOCKER — ChartSpec vocabulary cannot express the flagship 10k-year chart** (no splice, no BP→CE conversion, no cross-dataset rebaselining; splice/resolution annotation and modern-blade axis treatment unaddressed). → **Fixed:** `splice_series` (mandatory splice annotation), `time_axis` BP→CE, `rebaseline_to` (alignment periods fixed in dataset manifest, never LLM-chosen), context+recent-inset panel type; Phase-0 spike validates vocabulary against the flagship before freezing.
3. **MAJOR — chart data-faithfulness metric tautological/false as stated; exact float equality brittle.** → **Fixed:** gold fixtures computed independently of the pipeline, tolerances 1e-9/1e-6.
4. **MAJOR — runtime vs eval-time boundary ambiguous; cost model omitted runtime calls.** → **Fixed:** explicit split (batched runtime citation-support validation, post-stream "unverified" badges, no runtime regeneration; judges eval-only); §9 cost model rebuilt (~$0.012/query).
5. **MAJOR — severity-fidelity eval unimplementable as written; blind to retrieval-stage severity skew.** → **Fixed:** 3-point ordinal human annotations with source passages; gate ≥90% exact-or-adjacent, zero two-level errors; subset grown to ~15; severity-retrieval recall check on gold headline chunks.
6. **MAJOR — corpus severity-skewed high (Hansen in, assessed ranges out).** → **Fixed:** `consensus_position: beyond-assessed-range` manifest flag + system-prompt rule 8 + gold items; assessed-range statements (IPCC curated set or NCA5 fallback) made a hard launch dependency.
7. **MAJOR — privacy/UK GDPR entirely absent.** → **Fixed:** new §9 privacy section (retention, IP hashing, eval-harvest review, disclosure line, privacy page, ICO check).
8. **MAJOR — Phase 1 at 4–5 weeks not credible; long pole misidentified.** → **Fixed:** re-planned to 6–8 weeks; long pole named as ingestion-QA → gold-set curation; cut iframe embeds, warming stripes, four pack datasets.
9. **MAJOR — NC-reliance grey zone unowned.** → **Fixed:** NC-confirmation letters to Carbon Brief and Berkeley Earth added to Phase 1.5 week-1.
10. **MAJOR — Berkeley Earth "bundle" contradicted invariant; pack NC-freedom unstated.** → **Fixed:** fetch-script-only wording; explicit invariant that the chart data pack contains only `open` datasets.
11. **MAJOR — IPCC headline-statements position overstated; shipped on internal sign-off only.** → **Fixed:** capped ≤10 statements per SPM, feature-flagged, set named in the permission letter; Carbon Brief close-paraphrase gold item added.
12. **MAJOR — emergency framing risks repelling the stated primary audience.** → **Fixed:** reach model made explicit (second-hand sharing as primary conversion path), landing-variant testing committed, persuadable-sceptic reception added to the adversarial rubric.
13. **MINOR — "BM25" vs learned sparse; "calibrated" vs query-comparable.** → **Fixed** per ADR wording.
14. **MINOR — voices separation enforced by prompt when a structural filter is free.** → **Fixed:** in-code voices filter; eval verifies the filter.
15. **MINOR — gate arithmetic brittle on tiny subsets.** → **Fixed:** no-answer set to ~20 items, calibration/gate items disjoint; severity subset ~15.
16. **MINOR — fail-closed "dark" state is a mission failure at peak virality.** → **Fixed:** cached read-only paused state (pre-generated starter answers + flagship charts).
17. **MINOR — `unsafe` handling unspecified; no abuse posture.** → **Fixed:** canned per-subtype responses, self-harm signposting, no LLM call, excluded from eval harvest.
18. **MINOR — chart accessibility/mobile gaps.** → **Fixed:** spec-derived alt text, responsive caption rule, CSV attribution headers.
19. **MINOR — multilingual behaviour and update cadence unspecified.** → **Fixed:** answer-in-English MVP rule; quarterly corpus / monthly datasets cadence; corpus vintage in footer.
20. **NIT — cross-document hygiene** (gold-set counts, timeline mentions, repo dirs, §4.11 reference, Kaufman PD assumption). → **Fixed** in both documents; ADR v3.1 amendments section added.

## What the design gets right (preserved through revision)

1. Guaranteed-vs-measured framing (ADR-009, Appendix B) — the single best idea in the document.
2. Permission-first licensing with the hardened gate (ADR-003) and the Ripple free-to-read ≠ licensed catch.
3. The reranker-as-refusal-gate argument (ADR-006).
4. Closed ChartSpec, never codegen, integrity rules in the renderer (ADR-020) — finding 2 asks for a bigger vocabulary, not a different design.
5. Voices/evidence separation as a tested invariant (ADR-019) — finding 14 makes it structural.
6. Fail-closed budget cap (ADR-015) and refuse-and-log over web fetch (ADR-021).
7. Custom-content citation blocks as the epistemic unit (ADR-008) — qualifier-stays-with-claim is subtle and load-bearing.
8. Eval-as-published-deliverable (ADR-014) and the honest "When you'd choose differently" ADR sections.
