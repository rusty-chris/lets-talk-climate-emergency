## Context
DESIGN §2.5. First-party descriptive text about the movement (NEB campaign, named experts, Packham, Ripple warnings link-only, warming stripes, Climate Majority Project, Covering Climate Now, David King/CCAG) — ingested as `source_type: voices`, never cited for scientific claims.

## Scope
- `voices/voices.yaml`: entities with links, one-line descriptions, snapshot facts carrying `as_of` dates (petition counts, MP counts, screenings — see DESIGN §1 for the verified 2026-08 facts).
- First-party prose (a few paragraphs per entity cluster), descriptive not promotional, authored fresh (freely licensable).
- Ingest through #7 with `source_type: voices` and distinct attribution ("About the movement").

## Acceptance criteria
- `test_voices_chunks_labelled_source_type_voices`, `test_voices_attribution_is_about_the_movement` and `test_snapshot_facts_carry_as_of_dates` pass; retrievability verified by `test_real_voices_yaml_ingests_and_is_retrievable`.
- Content reviewed by the project owner before merge (editorial sign-off recorded in the PR).

## TDD plan
Mostly data validation (unit) plus one ingestion integration test; the prose itself is editorially reviewed, not tested. Order:
1. `test_voices_yaml_schema_valid` (unit) — every entity has name, canonical link, one-line description.
2. `test_snapshot_facts_carry_as_of_dates` (unit) — any numeric snapshot fact (petition count, MP count, screenings) without `as_of` fails.
3. `test_voices_chunks_labelled_source_type_voices` (unit) — ingesting the voices fixture through #7's pipeline marks every chunk `source_type: voices`.
4. `test_voices_attribution_is_about_the_movement` (unit) — voices chunks carry the distinct attribution label, never a scientific-source attribution.
5. `test_real_voices_yaml_ingests_and_is_retrievable` (integration) — the actual `voices/voices.yaml` content ingests; a "who is calling for a briefing?" query returns voices chunks once #9's index exists.
Editorial sign-off is a process criterion recorded in the PR, not a test.
