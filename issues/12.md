## Context
DESIGN §3.3, §3.4, §5, ADR-008/012. The core answer path.

## Scope
- Thin provider adapter `generate(messages, documents, config) -> AnswerWithCitations`; Anthropic implementation with custom-content document blocks, `citations: {enabled: true}`, prompt caching on the static prefix; model id config (`claude-haiku-4-5` default, `claude-opus-4-8` behind the budget sub-cap).
- System prompt implementing the 8 rules of §3.3 — including rule 4 (lead with the headline finding at source severity) and rule 8 (`beyond-assessed-range` labelling).
- SSE streaming with citation events; enforce §3.4 constraints (no structured output on this call; all-or-none citations; top-8 documents only).
- Response footer (verification note + corpus vintage date).

## Acceptance criteria
- Integration test: cited answer streams end-to-end from a live query against the indexed corpus.
- Constraint violations (mixing structured output, >8 docs) raise before the API call.
- Prompt-cache hit rate visible in logs.
