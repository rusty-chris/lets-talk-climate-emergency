## Context
DESIGN §3.2, §3.5, ADR-006. The reranker's query-comparable scores are what make the refusal gate trustworthy; the voices filter is structural, not prompt-based.

## Scope
- bge-reranker-v2-m3 over hybrid top-40 → top-8 (CPU, ~100 ms budget).
- **Structural filter:** for every non-`voices` query, drop `source_type: voices` chunks in code before the generation call.
- Refusal gate thresholding on top reranker score(s); threshold calibrated on the gold set's calibration items (#20) — calibration/gate items disjoint.
- Honest-refusal response path: what the corpus does cover, per §3.5.

## Acceptance criteria
- `test_voices_chunks_removed_for_non_voices_query` and `test_filter_applies_before_generation_document_set` pass; the live-pipeline structural check is #21's voices-separation eval.
- Threshold calibration procedure scripted and reproducible (not hand-tuned magic).
- Rerank latency measured and recorded by `test_rerank_latency_recorded`; the ~100 ms budget verified on the demo hardware profile before release (recorded in the perf log).

## TDD plan
Filter and gate logic are pure (IMPLEMENTATION.md §1) — test them with injected scores and synthetic chunk lists before touching the real reranker. Order:
1. `test_voices_chunks_removed_for_non_voices_query` (unit) — mixed chunk list + non-voices classification → zero `source_type: voices` chunks survive.
2. `test_voices_chunks_retained_for_voices_query` (unit) — the control.
3. `test_filter_applies_before_generation_document_set` (unit) — the document set handed to the generation call is post-filter; asserted at the seam, not hoped of the model.
4. `test_refusal_below_threshold` / `test_no_refusal_at_threshold` (unit) — injected reranker scores either side of the boundary.
5. `test_refusal_response_names_covered_topics` (unit) — the refusal payload lists what the corpus does cover (§3.5).
6. `test_threshold_calibration_reproducible` (unit) — the calibration script yields an identical threshold from identical score inputs (no hand-tuned magic).
7. `test_calibration_items_disjoint_from_gate_items` (unit) — the two no-answer subsets share no ids (guards the §6.1 rule as #20's data lands).
8. `test_reranker_orders_relevant_fixture_chunk_first` (integration — real bge-reranker over the synthetic corpus).
9. `test_rerank_latency_recorded` (integration) — measures top-40 rerank wall-clock into the perf log; the ~100 ms budget is checked on the demo hardware profile at release, not asserted on CI hardware.
