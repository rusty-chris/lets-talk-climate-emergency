## Context
DESIGN §3.2, §3.5, ADR-006. The reranker's query-comparable scores are what make the refusal gate trustworthy; the voices filter is structural, not prompt-based.

## Scope
- bge-reranker-v2-m3 over hybrid top-40 → top-8 (CPU, ~100 ms budget).
- **Structural filter:** for every non-`voices` query, drop `source_type: voices` chunks in code before the generation call.
- Refusal gate thresholding on top reranker score(s); threshold calibrated on the gold set's calibration items (#20) — calibration/gate items disjoint.
- Honest-refusal response path: what the corpus does cover, per §3.5.

## Acceptance criteria
- Filter verified by test: voices chunks never appear in a science query's document set.
- Threshold calibration procedure scripted and reproducible (not hand-tuned magic).
- Latency within budget on the demo hardware profile.
