## Context
DESIGN §3.3 runtime/eval-time split. Entailment is measured, not guaranteed; at runtime we flag, we don't regenerate.

## Scope
- After generation completes: one batched Haiku call checking every factual-sentence → cited-block pair for entailment.
- Sentences failing entailment get an "unverified" badge applied to their citation chips after the stream finishes (UI contract with #18).
- Aggregate rate logged per exchange (feeds the published citation-support metric).
- Cost within the §9 model (~$0.003/query).

## Acceptance criteria
- `test_failing_sentence_gets_unverified_badge` passes against the committed corrupted-answer replay fixture; `test_supported_sentences_not_flagged` as the control.
- `test_badges_emitted_only_after_stream_complete` proves stream start never waits on validation; badge latency measured by `test_badge_latency_recorded` and checked against the ~2 s target on the demo hardware profile before release.

## TDD plan
Pairing and badge logic are pure; the entailment call goes through the adapter (IMPLEMENTATION.md §4). Order:
1. `test_sentence_pairing_covers_every_factual_sentence` (unit) — each cited sentence maps to its cited block(s); non-factual sentences excluded.
2. `test_exactly_one_batched_call` (unit, FakeAdapter) — all pairs checked in a single adapter call regardless of sentence count.
3. `test_failing_sentence_gets_unverified_badge` (unit, ReplayAdapter) — the recorded corrupted-answer fixture (real citation, non-entailing sentence) flags exactly the corrupted sentences.
4. `test_supported_sentences_not_flagged` (unit) — the control on the same fixture.
5. `test_badges_emitted_only_after_stream_complete` (unit) — event ordering: no badge event precedes stream end; stream start never waits on the validator.
6. `test_aggregate_support_rate_logged` (unit) — the per-exchange rate lands in the structured log (feeds the published metric).
7. `test_validator_failure_degrades_gracefully` (unit, FakeAdapter raising) — an errored validation call never blocks or retracts the answer; the exchange is logged as unvalidated.
8. `test_badge_latency_recorded` (integration) — measures badge-application time after stream end into the perf log.
