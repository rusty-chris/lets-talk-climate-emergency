## Scope
- Parse the paleo source files to CSV with committed parsers: Bereiter 2015 Antarctic CO₂ composite, Kaufman 2020 Temperature 12k (verify its licence — NOT assumed public domain), plus Mauna Loa CO₂ and GISTEMP.
- Hand-write the flagship ChartSpec exercising: `splice_series` (Bereiter+Mauna Loa; Kaufman+GISTEMP), `time_axis` BP→CE conversion, `rebaseline_to` with alignment periods fixed in a draft dataset manifest, context+recent-inset panel pair.
- Render via Vega-Lite / vl-convert: splice-point + resolution annotations, labelled baselines, caption strip (sources, licences, access date, site URL), PNG + SVG export.

- Any vocabulary gaps discovered are written up as required changes to #15 before it starts.
