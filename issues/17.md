## Context
DESIGN §3.7. Server-side, local, $0/chart; integrity enforced in the renderer, not requested of the model.

## Scope
- ChartSpec → Pandas transforms → Vega-Lite → SVG + PNG via vl-convert (no browser).
- Integrity defaults: labelled baselines/reference periods, per-type y-axis zero rules with annotated non-zero baselines, uncertainty bands where shipped, splice/resolution annotations, per-axis colour-matched labels on dual-axis, colour-blind-safe palette, direct labelling.
- Caption strip baked into exports (sources, licences, access date, site URL) with the responsive minimum-width rule; CSV export with attribution header comments; alt text generated deterministically from the spec.
- `/chart/<spec-hash>` permalink: store spec, re-render against pinned dataset versions (route lives in #22's FastAPI service).

## Acceptance criteria
- Flagship + gold-set charts render with all integrity elements present (`test_flagship_svg_snapshot` plus the Vega-Lite-JSON integrity tests).
- Rendered values match #20's committed fixtures within tolerance (1e-9 pass-through / 1e-6 post-transform).
- `test_caption_strip_below_min_width_drops_to_short_form` passes for a 360 px render.
