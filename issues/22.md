## Context
DESIGN §9, ADR-015 as amended. The cap must never take the briefing fully offline.

## Scope
- FastAPI: SSE chat endpoint, chart permalink routes (#17), static pages.
- Hard daily spend cap tracked server-side; on breach, fail closed to **read-only**: pre-generated cached starter-topic answers + flagship charts (generated at release time, clearly dated), /about + source library + voices + permalinks still served; Opus behind a lower sub-cap.
- Per-IP rate limiting with hashed IPs (rotating salt, ≤7-day retention, never joined to query logs).
- Structured JSON logging per the privacy policy: 90-day retention job, eval-harvest review flow (hand-review + irreversible detachment), unsafe-content exclusion.
- Deploy: Docker Compose on Fly.io/Railway small VM (or equivalent) within the <£20/month target; ICO-registration check recorded before public launch.

## Acceptance criteria
- **GATE (DESIGN §10): cut-off verified to fail closed to the cached read-only state** (integration test simulating breach).
- Rate limiter and retention jobs covered by tests; log samples contain no raw IPs or identifiers.
- One-command deploy documented and executed to a staging URL.
