## Context
DESIGN §2.1 invariants — the legal load-bearing wall. The adversarial review (blocker 1) re-keyed everything on `permitted_context`; implement exactly that.

## Scope
- `corpus/manifest.yaml` schema + validator: `licence`, `licence_evidence`, `attribution_text`, `canonical_url`, `redistributable`, `permitted_context: open | non-commercial-educational | permission-on-file`, `permission_evidence`, `consensus_position` (default `assessed`), `sha256`, `retrieved_at`, `source_tier`, `human_signoff {who, date, note}`.
- Build refuses to index any document with unset `permitted_context`, empty `human_signoff`, or `permission-on-file` without `permission_evidence`.
- Repo-shipping check: CI fails if prepared text exists in-repo for any document whose `permitted_context` != `open`.
- Same schema discipline for `datasets/manifest.yaml` incl. the pack invariant: **only `open` datasets in the chart data pack**, plus per-pair splice/rebaseline alignment periods.
- `make corpus`: re-fetch, verify sha256, run all invariants.

## Acceptance criteria
- Every refusal path has a named unit test (see TDD plan) asserting build failure with a message naming the offending document and field.
- The committed mis-tiered fixture (NC doc with in-repo prepared text) fails the ship check via `test_ship_check_fails_on_nonopen_prepared_text`, which runs in CI's unit stage.

## TDD plan
Pure-unit territory (IMPLEMENTATION.md §1); classic red–green. Write failing tests in this order, all unit unless marked:
1. `test_manifest_parses_minimal_valid_entry` — a fully populated `open` entry loads with all §2.1 fields typed.
2. `test_build_refuses_unset_permitted_context` — indexing a document with no `permitted_context` fails the build.
3. `test_build_refuses_unknown_permitted_context_value` — values outside `open | non-commercial-educational | permission-on-file` rejected.
4. `test_build_refuses_empty_human_signoff` — missing or incomplete `{who, date, note}` fails.
5. `test_build_refuses_permission_on_file_without_evidence` — `permission-on-file` with empty `permission_evidence` fails.
6. `test_refusal_messages_name_document_and_field` — every refusal names the offending document id and violated field.
7. `test_ship_check_fails_on_nonopen_prepared_text` — a fixture repo tree containing prepared text for a `non-commercial-educational` doc fails the check; `test_ship_check_passes_open_prepared_text` as the control.
8. `test_dataset_pack_rejects_nonopen_dataset` — a non-`open` dataset in the chart pack manifest fails.
9. `test_dataset_manifest_requires_alignment_periods_for_splice_pairs` — a splice-able pair without fixed alignment periods fails.
10. `test_consensus_position_defaults_to_assessed` — omitted field defaults correctly.
11. `test_make_corpus_runs_all_invariants` (integration) — `make corpus` against the fixture manifest exercises fetch → sha256 → invariants and fails on the deliberately mis-tiered fixture.
