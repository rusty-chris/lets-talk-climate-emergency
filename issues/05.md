## Context
DESIGN §2.1 invariants — the legal load-bearing wall. The adversarial review (blocker 1) re-keyed everything on `permitted_context`; implement exactly that.

## Scope
- `corpus/manifest.yaml` schema + validator: `licence`, `licence_evidence`, `attribution_text`, `canonical_url`, `redistributable`, `permitted_context: open | non-commercial-educational | permission-on-file`, `permission_evidence`, `consensus_position` (default `assessed`), `sha256`, `retrieved_at`, `source_tier`, `human_signoff {who, date, note}`.
- Build refuses to index any document with unset `permitted_context`, empty `human_signoff`, or `permission-on-file` without `permission_evidence`.
- Repo-shipping check: CI fails if prepared text exists in-repo for any document whose `permitted_context` != `open`.
- Same schema discipline for `datasets/manifest.yaml` incl. the pack invariant: **only `open` datasets in the chart data pack**, plus per-pair splice/rebaseline alignment periods.
- `make corpus`: re-fetch, verify sha256, run all invariants.

## Acceptance criteria
- Unit tests cover every refusal path (each invariant violated → build fails with a clear message).
- A deliberately mis-tiered fixture (NC doc marked for in-repo shipping) fails CI.
