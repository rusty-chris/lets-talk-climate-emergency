## Context
DESIGN §3.7 MVP pack: GISTEMP v4, HadCRUT5, Mauna Loa + global CO₂, Bereiter 2015 ice-core CO₂ composite, Kaufman 2020 Temp-12k, OWID co2-data. Pack must be `open`-licensed only (invariant in #5).

## Scope
- `datasets/manifest.yaml` entries per #5's schema: provenance, licence, attribution string, sha256, update script, version, splice/rebaseline alignment periods per dataset pair.
- Fetchers + one-time paleo TXT→CSV parsers (productionised from #4), committed with tests.
- **Kaufman 2020 licence verified at bundling** (author-contributed archive data — not assumed public domain; record evidence; if not open, find an open Holocene reconstruction replacement and update DESIGN).
- `make datasets` refresh; versions pinned per corpus release.

## Acceptance criteria
- All six datasets fetch, parse and validate reproducibly: parser unit tests against committed samples; `test_fetch_all_datasets_verify_sha256` and `test_make_datasets_idempotent` in scheduled CI.
- Every dataset's licence evidence recorded (`test_kaufman_licence_evidence_recorded` covers the load-bearing case); `test_pack_contains_only_open_datasets` passes.

## TDD plan
Parsers and validation are pure over committed sample files; live fetching is scheduled-CI territory (IMPLEMENTATION.md §3, §6). Order:
1. `test_bereiter_txt_parses_expected_columns` (unit) — committed truncated sample of the real TXT format → typed CSV with age/CO₂ columns.
2. `test_kaufman_txt_parses_expected_columns` (unit) — same for Temp-12k, covering the header/units quirks found in #4.
3. `test_parser_rejects_malformed_rows` (unit) — a corrupt sample fails loudly, never silently drops rows.
4. `test_every_pack_dataset_has_manifest_entry` (unit) — six entries, each passing #5's dataset schema.
5. `test_pack_contains_only_open_datasets` (unit) — #5's pack invariant run over the real manifest.
6. `test_alignment_periods_present_for_splice_pairs` (unit) — the Bereiter+Mauna Loa and Kaufman+GISTEMP pairs carry fixed alignment periods.
7. `test_kaufman_licence_evidence_recorded` (unit) — the manifest entry carries non-empty licence evidence (the load-bearing check's paper trail).
8. `test_dataset_validation_schema_and_rowcount_sanity` (unit) — committed small CSVs pass; a truncated file fails.
9. `test_fetch_all_datasets_verify_sha256` (integration, network — scheduled CI, not per-PR) — real fetch of all six, hash-verified.
10. `test_make_datasets_idempotent` (integration) — re-run with unchanged upstreams changes nothing.
The Kaufman licence verification itself is a process step: evidence recorded in the manifest before the dataset ships; if not open, the replacement decision is recorded here and DESIGN updated.
