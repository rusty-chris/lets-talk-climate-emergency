## Context
DESIGN §6.1 as amended by the review. This is on the critical path (gold chunk-ids need stable chunking) — start the chunk-independent subsets (no-answer, chart golds) as soon as #16's catalogue shape is known; finish after #7 stabilises.

## Scope
- Climate-QA (~75): ~15 single-passage, ~10 multi-passage (gold chunk_ids each), ~20 no-answer (calibration and gate items disjoint), ~7 adversarial/denialist, ~15 severity-sensitive with 3-point ordinal lead-severity annotations (reassuring/serious/emergency-level) + source passage, ~5 voices/action; targeted items: Packham-phrased science question, sensitivity/committed-warming (assessed-range retrieval + Hansen labelling), Carbon-Brief paraphrase check.
- Chart gold set (15): expected ChartSpec or expected refusal; **expected rendered values computed by an independent script/hand and committed as fixtures** with tolerances; includes flagship, cherry-pick attempt, unit/baseline edge cases.
- Persuadable-sceptic reception rubric items for the adversarial set.

## Acceptance criteria
- Every gold item peer-reviewed by a second pass (agent or human) for answerability and annotation quality; severity annotations spot-audited by the project owner.
- Fixture-generation script committed; independence from `charts/` enforced by `test_fixture_script_imports_nothing_from_charts`.
- Gold-set structure tests (schema, category mix, calibration/gate disjointness, chunk-id resolution) pass in CI.

## TDD plan
A data-authoring issue: TDD here means meta-tests that make the gold sets structurally trustworthy. Write them against 2–3 seed items first, then author the rest against green structure checks. Order:
1. `test_gold_item_schema_valid` (unit) — every item has question, category, expected behaviour (answer/refusal), and gold `chunk_id`s where its category requires them.
2. `test_gold_category_counts_match_design_mix` (unit) — the §6.1 mix (~15/~10/~20/~7/~15/~5 plus targeted items) enforced, so the set cannot silently shrink.
3. `test_no_answer_calibration_and_gate_items_disjoint` (unit) — zero shared ids between the calibration and gate subsets.
4. `test_severity_items_carry_ordinal_annotation_and_source_passage` (unit) — every severity item has a 3-point label and the passage it derives from.
5. `test_targeted_items_present` (unit) — Packham-phrased, sensitivity/committed-warming, and Carbon-Brief-paraphrase items exist and are tagged.
6. `test_chart_golds_have_spec_or_refusal` (unit) — every chart item carries exactly one of expected spec / expected refusal; specs pass #15's validator.
7. `test_chart_fixture_values_present_with_tolerances` (unit) — every expected-spec item has committed expected rendered values and a stated tolerance.
8. `test_fixture_script_imports_nothing_from_charts` (unit) — import-graph check proving the fixture-generation script is independent of the pipeline under test (the non-tautology guarantee).
9. `test_gold_chunk_ids_exist_in_index` (integration) — every referenced `chunk_id` resolves in the current corpus version; runs on every corpus-version bump.
Peer review of item quality and the owner's severity spot-audit are process criteria, recorded in the PR.
