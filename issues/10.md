## Context
DESIGN §3.1. Separate structured-output Haiku calls (native-citations incompatibility, §3.4).

## Scope
- Query rewriter: resolve conversational references, expand acronyms (structured output).
- Scope classifier: `in_scope | chart_request | voices | out_of_scope | adversarial_in_scope | unsafe`.
- Unsafe handling: canned responses per subtype, self-harm signposting (Samaritans 116 123), **no LLM generation call**; unsafe exchanges excluded from eval harvesting.
- Non-English detection: answer in English with the one-line explanatory note.
- Routing: `chart_request` → chart pipeline (#16); `voices` → voices-biased retrieval; adversarial → tone flag.

## Acceptance criteria
- Labelled ~40-query set committed; a committed script reports live-model per-class accuracy into the release eval results (#21). Release gate: 100% recall on the labelled unsafe items.
- Classifier and rewriter are separate adapter calls that never enable citations, verified by `test_structured_calls_never_enable_citations` and FakeAdapter call recording.

## TDD plan
All model calls go through the provider adapter (#24): FakeAdapter for behaviour-around-the-model, ReplayAdapter for response shapes; live accuracy is a release eval, never a unit test (IMPLEMENTATION.md §4). Order:
1. `test_classifier_output_schema_validates` (unit, replay fixture) — parses into the six-class enum; `test_malformed_classifier_output_handled` — a malformed fixture triggers the defined failure path, never a crash.
2. `test_structured_calls_never_enable_citations` (unit, contract) — rewriter/classifier request builders never carry citations config (the §3.4 mirror image).
3. `test_unsafe_self_harm_returns_signposting_canned_response` (unit, FakeAdapter) — response contains the Samaritans signpost.
4. `test_unsafe_path_makes_no_generation_call` (unit) — FakeAdapter records zero `generate` calls for `unsafe` inputs.
5. `test_unsafe_exchange_marked_excluded_from_harvest` (unit) — the log record carries the exclusion flag (#22 consumes it).
6. `test_non_english_input_sets_english_answer_note` (unit) — detector flags a non-English query; the routed request carries the one-line-note instruction.
7. `test_chart_request_routes_to_chart_pipeline`, `test_voices_class_sets_retrieval_bias`, `test_adversarial_sets_tone_flag` (unit) — routing is pure over the classification.
8. `test_rewriter_resolves_reference_replay` (unit, ReplayAdapter) — a recorded rewrite resolving a conversational reference against context.
9. Live-model per-class accuracy on the ~40-query labelled set: committed script, reported through #21's release evals — not a pytest gate.
