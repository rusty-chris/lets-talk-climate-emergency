## Context
DESIGN §3.2, ADR-005/007. Local bge-m3 producing dense + learned sparse vectors (NOT classical BM25), Qdrant with server-side RRF fusion.

## Scope
- Embedding job over #7's chunks: dense + sparse vectors, idempotent/incremental by content hash.
- Qdrant collection setup (Docker + embedded modes), hybrid query with RRF, top-40.
- Index versioning tied to corpus version.

## Acceptance criteria
- Full-corpus index builds on CPU in the documented time; re-run with no changes re-embeds nothing.
- Hybrid query returns fused top-40 with chunk metadata intact.
- Smoke test: known query → expected document family in top-10.
