## Context
DESIGN §10 Phase 0 gate. Proves the core mechanism — Claude native citations over custom-content document blocks — before anything is productionised.

## Scope
- Notebook (or thin script) over the spike chunks from #2: bge-m3 embeddings, naive top-k retrieval, bge-reranker-v2-m3 rerank, generation call with custom-content document blocks and `citations: {enabled: true}` (one block per chunk).
- Respect native-citations constraints (DESIGN §3.4): no structured output on the generation call; all-or-none citations.
- Author a 20-question probe over the spike documents; run it; record per-question whether citations resolve to the correct source blocks.

## Acceptance criteria
- **GATE (DESIGN §10): ≥18/20 questions cite the correct source blocks.**
- Probe results and any qualifier-splitting observations committed to `reviews/`.
