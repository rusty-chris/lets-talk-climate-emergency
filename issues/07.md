## Context
DESIGN §2.4. Productionise the #2 spike across all MVP sources (Tier A + gated Tier B, §2.1/2.3): NCA5 chapters, NASA/NOAA/Met Office explainers, C3S ESOTC, Hansen 2023+2025, OWID explainers, UNEP EGR, Carbon Brief (verbatim chunks), gate-passed reviews.

## Scope
- Per-source fetchers keyed off the manifest (#5); HTML parsing direct, PDFs via Docling with PyMuPDF fallback, handling the failure modes recorded by #2.
- Structure-aware chunker (section-bounded, ≤~500 tokens, context headers); IPCC curated headline statements (if the feature flag is enabled by #23's legal check): one statement = one chunk, capped ≤10 per SPM.
- Citation metadata per chunk per DESIGN §2.4 schema, incl. `confidence_markers` regex extraction and `consensus_position` propagation (Hansen papers → `beyond-assessed-range`).
- Emit custom-content citation blocks, one per citable unit.
- **Launch dependency (DESIGN §2.3):** assessed-range statements for sensitivity/committed warming/warming levels present via IPCC curated set or NCA5 equivalents — verify presence with a checked test.

## Acceptance criteria
- `make corpus` ingests every signed-off MVP document end-to-end reproducibly (hash-stable chunk ids).
- Chunk-quality hand-audit checklist completed per source family and committed.
- Assessed-range-statements presence test passes.
