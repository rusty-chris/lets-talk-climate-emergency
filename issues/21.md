## Context
DESIGN §6.2–6.3 as amended. Evaluation is a first-class published deliverable; gates block release.

## Scope
- Deterministic metrics: Recall@8 / MRR / nDCG@8 vs gold chunk_ids; severity-retrieval recall on headline chunks; chart spec accuracy; chart data-faithfulness vs fixtures (stated tolerances); chart refusal; voices-separation structural check; calibrated-term regex proxy.
- LLM-judge metrics (judge ≠ generator, sampled human audit): faithfulness/entailment, confidence-level fidelity, **severity fidelity** (3-point ordinal vs gold annotation; gate ≥90% exact-or-adjacent, zero two-level errors), citation-support.
- Refusal metrics: >90% on the 20-item no-answer gate subset; false-refusal <5%.
- CI wiring: retrieval + smoke per PR; full suite per release/corpus version; results to `evals/RESULTS.md` (consumed by #19); A/B harness for pipeline changes.

## Acceptance criteria
- One command runs the full suite reproducibly; gates fail the release build when violated.
- RESULTS.md format stable and rendered on /about.
