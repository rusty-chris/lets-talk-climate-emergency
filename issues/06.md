## Context
DESIGN §2.2. Automated licence lookups disagree ~37% of the time; the Ripple papers (free-to-read but all-rights-reserved) are exactly the trap this catches.

## Scope
- CLI: given a DOI, query OpenAlex + Crossref + Unpaywall; candidate only if ≥2 agree on CC BY / CC BY-SA / CC0; disagreement → reject with the evidence shown.
- Fetch the publisher article page/PDF; extract and store the verbatim licence statement + URL into `licence_evidence` for human confirmation.
- Interactive sign-off step writing `human_signoff` into the manifest; no document enters the index without it (enforced by #5).

## Acceptance criteria
- Run against the ~10–15 candidate review papers (DESIGN §2.3); manifest entries produced with evidence.
- Regression test: a known free-to-read-but-not-CC DOI (e.g. Ripple 2019, 10.1093/biosci/biz088) is **rejected** at the candidate stage or flagged at publisher-page stage.
