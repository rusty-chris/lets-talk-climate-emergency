## Context
DESIGN §2.2. Automated licence lookups disagree ~37% of the time; the Ripple papers (free-to-read but all-rights-reserved) are exactly the trap this catches.

## Scope
- CLI: given a DOI, query OpenAlex + Crossref + Unpaywall; candidate only if ≥2 agree on CC BY / CC BY-SA / CC0; disagreement → reject with the evidence shown.
- Fetch the publisher article page/PDF; extract and store the verbatim licence statement + URL into `licence_evidence` for human confirmation.
- Interactive sign-off step writing `human_signoff` into the manifest; no document enters the index without it (enforced by #5).

## Acceptance criteria
- Run against the ~10–15 candidate review papers (DESIGN §2.3); manifest entries produced with evidence.
- `test_ripple_2019_free_to_read_rejected` passes against committed recorded lookup/page fixtures for DOI 10.1093/biosci/biz088 — **rejected** at candidate stage or flagged at publisher-page stage, with no live network in the test.

## TDD plan
Decision logic is pure over injected lookup clients (IMPLEMENTATION.md §1, §5); all lookups in tests are recorded fixtures — no live network in the unit tier. Order:
1. `test_two_of_three_agreement_admits_candidate` (unit) — recorded OpenAlex+Crossref agreeing on CC BY, Unpaywall silent → candidate.
2. `test_no_two_source_agreement_rejects_with_evidence` (unit) — disagreement fixture rejects, and the output shows each source's claim.
3. `test_ripple_2019_free_to_read_rejected` (unit, regression) — recorded fixtures for DOI 10.1093/biosci/biz088 → rejected at candidate stage or flagged at publisher-page stage. The trap case this gate exists for.
4. `test_hybrid_journal_article_level_licence_wins` (unit) — journal-supports-CC-BY but article-is-subscription fixture rejected.
5. `test_publisher_page_licence_statement_captured_verbatim` (unit) — stored publisher HTML fixture → exact licence text + URL land in `licence_evidence`.
6. `test_publisher_page_contradicting_lookups_flags` (unit) — page says all-rights-reserved despite agreeing lookups → flagged, never admitted.
7. `test_signoff_step_writes_human_signoff` (unit) — interactive step (input injected) writes `{who, date, note}`.
8. `test_unsigned_candidate_never_reaches_manifest` (unit) — the gate's own behaviour; #5's validator is the backstop.
9. `test_gate_cli_end_to_end_on_recorded_doi` (integration) — CLI over the recorded fixture set produces a manifest entry with evidence.
The live run over the real candidate papers is task output (evidence recorded in the manifest), not a test.
