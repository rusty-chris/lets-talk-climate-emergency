## Context
DESIGN §3.7. `chart_request`-classified queries route here; a separate structured-output Haiku call (never the citations call).

## Scope
- Planner prompt with the dataset catalogue + ChartSpec schema; structured output validated against #15 (retry once on schema mismatch).
- Unavailable-data path: honest refusal naming the nearest available datasets; gap logged for pack curation (ADR-021 — no web fetch in MVP).
- Cost ~$0.002/chart per the §9 model.

## Acceptance criteria
- The 15 gold chart requests (#20) score correct specs / correct refusals in the release eval (#21); the flagship case additionally pinned by `test_flagship_request_replay_produces_expected_spec`.
- `test_cherry_pick_replay_yields_full_context_default` pins the "show cooling since 2016" behaviour; re-verified live per release.

## TDD plan
Planner behaviour around the model is deterministic via #24's adapters; live spec accuracy is a release eval via #21 (IMPLEMENTATION.md §4.4). Order:
1. `test_planner_call_is_structured_output_never_citations` (unit, contract) — the planner request builder never enables citations.
2. `test_planner_output_validated_before_use` (unit, FakeAdapter) — every returned spec passes through #15's validator; an invalid spec never reaches the renderer.
3. `test_invalid_spec_retries_once_then_refuses` (unit, FakeAdapter sequence invalid → invalid) — exactly one retry, then honest failure.
4. `test_unavailable_data_refusal_names_nearest_datasets` (unit) — nearest-dataset suggestion is pure over the catalogue; a sea-level request names the closest available series.
5. `test_gap_logged_for_unavailable_request` (unit) — the refusal writes a curation-log record and attempts no web fetch (ADR-021).
6. `test_flagship_request_replay_produces_expected_spec` (unit, ReplayAdapter) — the recorded planner response for the flagship request equals the gold spec.
7. `test_cherry_pick_replay_yields_full_context_default` (unit, ReplayAdapter) — the recorded "show cooling since 2016" run pins the full-range default.
8. Live: the 15 gold chart requests scored for spec accuracy / correct refusal by #21's harness — a release gate, not a pytest gate.
