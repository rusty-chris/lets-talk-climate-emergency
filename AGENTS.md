# Agent sessions

Follow the version-control protocol in [CONTRIBUTING.md](CONTRIBUTING.md).

Key documents:
- `DESIGN.md` — current design document (source of truth for scope and architecture).
- `DECISIONS.md` — ADR log; record any decision that changes architecture, scope, licensing posture, or naming.
- `issues/` — the implementation task breakdown (23 modular issues with dependencies and acceptance criteria); publish to GitHub with `python3 scripts/publish_issues.py <owner>/<repo>` once the repo exists.
- `reviews/` — design-review reports.

Licensing is a first-order constraint in this project: never ingest or redistribute a source that has not passed the licensing gate recorded in `DESIGN.md`.
